AutoRIP

Conecte o aplicativo ao painel AutoRIP executando no servidor interno.

O QR deve conter somente a URL HTTP(S) do painel, sem senha, token, query ou fragmento. Use HTTPS quando o servidor estiver publicado na internet. Para uma rede local HTTP, configure explicitamente AUTORIP_BIND_HOST e AUTORIP_ALLOWED_HOSTS no servidor.
