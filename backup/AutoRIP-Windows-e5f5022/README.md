# Backup Windows AutoRIP

Build nativo final do AutoRIP para Windows, associado ao commit `e5f5022603013688dc922cb33300f4785724358b`.

- `AutoRIP_Setup.exe`: instalador recomendado.
- `AutoRIP.exe`: versão portátil one-file.
- O executável inicia no modo nativo sem navegador por padrão.
- O painel web é opcional e só deve ser aberto com `--web`.
- `SHA256SUMS.txt`: hashes para verificar a integridade após baixar do GitHub.

Os binários estão versionados apenas como backup. O código-fonte continua sendo a fonte principal do projeto.
