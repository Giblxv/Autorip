# AutoRIP v0.8.26

Em **Configurações → Conexão PrintExp**, o AutoRIP agora mostra seus IPv4 locais, procura o agente no computador receptor e permite verificar a conexão TCP. Um resultado único preenche o formulário; vários computadores ou interfaces exigem escolha. **Salvar** persiste o IP e a porta, cujo padrão é 9100. Respostas atrasadas preservam alterações digitadas pelo usuário.

O agente anuncia seus endereços via mDNS na LAN. Para usá-lo apenas na descoberta, sem observar arquivos ou imprimir, execute no computador PrintExp:

```powershell
.\PrintExpAgent.exe --network-discovery --print-port 9100
```

A configuração manual continua disponível quando a rede bloqueia descoberta. **Verificar conexão** abre e fecha uma conexão TCP sem transmitir dados de impressão. A descoberta identifica um agente AutoRIP e não certifica o protocolo nativo PrintExp.

Esta versão configura e verifica o destino; o envio de PRT pelo protocolo nativo PrintExp ainda depende de implementação e validação. Os parâmetros de rasterização, canais, branco e firmware permanecem separados desses controles de rede.

Os testes abrangem autorização da API, validação dos endereços, persistência, múltiplas interfaces, encerramento de recursos, ausência de dados no teste TCP e respostas atrasadas no painel. O empacotamento Windows inclui uma consulta IPv4 sem impressão no executável do agente, além dos smokes do AutoRIP e do instalador.
