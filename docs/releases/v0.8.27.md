# AutoRIP v0.8.27

O agente PrintExp agora acompanha mudanças de IPv4 e de interface de rede durante a execução. O anúncio mDNS é recriado com os endereços atuais; uma falha temporária de registro é tentada novamente. O modo dedicado de descoberta permanece aguardando se iniciar antes de o computador obter um IPv4.

O painel descarta anúncios retirados ou substituídos durante a busca, atualiza as interfaces locais a cada nova descoberta e ignora consultas antigas que chegam atrasadas. Editar o IP ou a porta remove a mensagem anterior de conexão bem-sucedida e solicita nova verificação.

Depois de uma mudança de IP, use **Configurações → Conexão PrintExp → Buscar PrintExp na rede** e **Salvar** para atualizar o destino persistido. Atualize também o `PrintExpAgent.exe` no computador receptor: a versão do agente passa a 0.1.1 e aparece no diagnóstico `--network-info`.

A descoberta e a verificação TCP continuam sem enviar comandos de impressão ou arquivos PRT. O envio pelo protocolo nativo PrintExp permanece uma integração futura.
