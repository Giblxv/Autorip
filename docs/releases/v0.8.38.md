# AutoRIP v0.8.38 — base branca opaca mais leve

Imagens RGB opacas passam a usar alfa booleano para preparar a base branca,
evitar matrizes de densidade e calcular as probabilidades uniformes uma única
vez. O alfa dessa etapa ocupa 75% menos memória. A retícula, as gotas,
a morfologia, o ICC, os canais e os bytes PRT são preservados.

Em dois ensaios Linux, o RGB largo com branco 100% levou 5,4–6,8% menos tempo,
com aproximadamente 11–13% menos pico total de RAM. Com branco 45%, a redução
de tempo foi 4,3–7,7%; uma conferência adicional em processos novos mediu 9,8%.
Os controles oscilaram, e nem todo caso demonstrou ganho estatístico.
[Resultados completos e limites](../refinements/OPAQUE-WHITE-MASK.md).

Validação local: **1.704 testes aprovados**, incluindo 96 novos casos, 30 artes
distintas comparadas byte a byte com a 0.8.37 e 140 pares de PRTs medidos com
SHA/metadados iguais, além de aquecimentos e verificações em processos novos.
Os pacotes Windows e o instalador passam pelos testes do GitHub Actions antes
de publicar.

RGBA com transparência parcial, limiar de alfa zero e métodos personalizados
mantêm seus caminhos compatíveis. As versões nativas do APK e do agente não
mudam; artes enviadas pelo celular usam o motor atualizado no servidor.
Não houve medição no computador do usuário nem prova física de impressão.
