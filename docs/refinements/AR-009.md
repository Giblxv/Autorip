# AR-009 — Tratar falhas do atualizador sem erro secundário

Quando a consulta da release falhava antes de criar os caminhos de download, o bloco de tratamento tentava acessar `manifest_path` e `installer_path` ainda não inicializados. Um erro de rede se transformava em `UnboundLocalError`, impedindo o registro normal da falha.

A proposta inicializa ambos os caminhos antes da consulta e só remove arquivos com caminho definido. Mantém as verificações SHA-256, HTTPS, hosts e limites de download existentes. Não executa atualizações nem altera o modo offline.

Os testes simulam ausência de rede e interrupção de cada download, verificando retorno seguro, registro do erro original e limpeza de arquivos parciais. O caso de rede falhou no código anterior com UnboundLocalError. Nenhuma chamada externa ou instalador real é usado nos testes; o modo empacotado é simulado.

Não houve teste do instalador Windows. Proposta independente para revisão, sem merge automático.

Validação: `python -m pytest -q` — **92 passed in 30.35s**. `git diff --check` sem problemas.
