# AR-010 — Recuperar cache inválido de consulta de atualizações

O cache de atualização era tratado como dicionário sem validar o tipo do JSON. Listas, null, textos ou números causavam AttributeError antes do tratamento normal. Um timestamp grande demais podia causar OverflowError. Uma data futura, por exemplo após ajuste do relógio, fazia a idade negativa parecer uma consulta recente e podia bloquear consultas por tempo indevido.

A proposta só reutiliza o cache quando ele é um objeto com checked_at cuja idade é não negativa e menor que 24 horas. Dados inválidos são tratados como cache ausente; o estado volta a ser gravado após a consulta normal. A conversão numérica também trata OverflowError.

Sete casos de regressão cobrem quatro tipos JSON inválidos, timestamp enorme, data futura e cache recente válido. Antes da mudança, seis falharam; o caso de cache recente passou. Os testes simulam a API e o relógio; não há chamadas externas, downloads ou instalação.

O limite de 24 horas, os controles offline/código-fonte e as verificações de download não são removidos. O recurso não muda o RIP. Não houve execução Windows. Proposta independente para revisão, sem merge automático.

Validação: `python -m pytest -q` — **96 passed in 30.55s**. `git diff --check` sem problemas.
