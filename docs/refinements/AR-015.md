# AR-015 — Iniciar modo direto quando não há display gráfico

A importação do Tkinter podia funcionar, mas `tk.Tk()` lançar TclError por falta de display ou indisponibilidade da janela. Esse erro escapava do fallback existente e impedia a inicialização do modo direto.

A proposta trata especificamente TclError na criação da janela e inicia o servidor local com open_browser=False, como já ocorre quando o Tkinter não pode ser importado. Não captura erros arbitrários de programação nem altera a janela em sistemas onde ela funciona.

Dois testes controlados cobrem Tkinter ausente e Tkinter disponível com falha de display. O segundo falhou antes da correção. A suíte completa passou: **92 passed in 30.02s**.

Um smoke test iniciou o script real autorip_gui.py --headless sem DISPLAY/WAYLAND_DISPLAY, usando dados temporários isolados. A API local respondeu com a pasta correta e offline=True; o processo iniciado no teste foi encerrado. Esse smoke confirma o fluxo sem GUI neste Linux, não a inicialização de uma janela Windows.

Não foram adicionadas dependências ou chamadas externas. Proposta para revisão, sem merge automático.
